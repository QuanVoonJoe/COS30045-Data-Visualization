About the Appliance Energy Website

This educational platform was developed for Exercise 0.2 (Build Appliance Energy Consumption Website) at Swinburne University of Technology. It demonstrates foundational multi-page web development using semantic HTML, structured CSS, and vanilla client-side JavaScript.

Unit Learning Objectives

In this unit, students learn how to engineer web-based data visualisations hosted on Swinburne's Mercury Apache server:

  • Structure a simple multi-page website using semantic HTML
  • Apply consistent styling across all pages via external CSS
  • Implement client-side interactivity using pure vanilla JS
  • Commit regular, meaningful progress to a GitHub repository
  • Reflect critically on Generative AI workflow integrations
